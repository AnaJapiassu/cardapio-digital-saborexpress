# 🍔 SaborExpress - Cardápio Digital Responsivo

Aplicação web responsiva (*Mobile-First*) desenvolvida como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS). O sistema permite que clientes naveguem pelo cardápio, filtrem produtos por categoria, montem um carrinho interativo e enviem pedidos estruturados diretamente via WhatsApp, além de contar com um painel administrativo para gestão de itens.

## 🌐 Acesso à Aplicação (Deploy)
* **Link do Sistema no Ar:** https://github.io

## 🚀 Funcionalidades Principais
* **Catálogo Responsivo:** Adaptação automática para smartphones, tablets e desktops.
* **Busca e Filtros:** Pesquisa em tempo real por nome e filtragem por categorias (*Todos, Lanches, Bebidas, Sobremesas*).
* **Carrinho Inteligente:** Adição, remoção, controle de quantidades e cálculo automático de valores.
* **Checkout Integrado:** Validação de dados do cliente (Entrega ou Retirada) e geração automática de resumo formatado para WhatsApp.
* **Painel Administrativo:** Cadastro de novos produtos e controle de disponibilidade (*Disponível* ou *Esgotado*) com persistência via `localStorage`.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estrutura semântica)
* **Tailwind CSS** (Estilização responsiva)
* **JavaScript ES6+** (Regras de negócio, manipulação do DOM e Web Storage API)
* **Git & GitHub Pages** (Versionamento e hospedagem)

## 💻 Como Executar Localmente
1. Clone este repositório:
   `git clone https://github.com`
2. Acesse a pasta do projeto e abra o arquivo `index.html` diretamente em qualquer navegador moderno (ou utilize a extensão *Live Server* no VS Code).
